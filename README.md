# 제3회 한마당 커뮤니티 몬스터 육성 배틀

제3회 한마당 참가 커뮤니티가 미션과 퀴즈로 몬스터를 키우고 공동 보스에 도전하는 웹앱입니다.

`public/expedition.html`에는 이동과 전투가 있는 개인 원정 ‘지식의 숲’을 추가했습니다. 코딩, 바이브코딩, 컴퓨터, 웹, 디지털 역사, AI, 안전, 데이터 분야의 120문제(주관식 40문제)를 풀며 경험치와 장비를 얻습니다. 새 문제의 첫 정답은 기존 커뮤니티 보상에도 반영됩니다.

2026-09-27 배포판은 개인 원정, 아바타 이름과 모습 저장, 장비 그림, 보스 공격 패턴과 스킬 효과를 포함합니다. 기존 주간 퀴즈와 사용자 기록 구조는 유지했습니다.

게임 주소: https://legoschool.github.io/hanmadang-monster-battle/expedition.html

- 화면: 이 저장소의 `public/` 폴더가 깃허브 페이지로 배포됩니다.
- 기록 서버: 수파베이스(Supabase)에서 따로 운영합니다. 서버 코드에는 퀴즈 정답이 들어 있어 이 저장소에 올리지 않습니다.
- 서버 주소는 `public/js/config.js`의 `SUPABASE_URL`에서 정합니다.
