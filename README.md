# G-DEAL 몬스터 원정대

G-DEAL 커뮤니티가 미션과 퀴즈로 몬스터를 키우고 공동 보스에 도전하는 이벤트 웹앱입니다. 운영자가 시작과 종료 시각을 정하면 그 사이를 4회차로 나눠 보스가 바뀌고, 종료 시각에 최종 결전이 열립니다.

`public/expedition.html`에는 이동과 전투가 있는 개인 원정 ‘지식의 숲’을 추가했습니다. 코딩, 바이브코딩, 컴퓨터, 웹, 디지털 역사, AI, 안전, 데이터 분야와 일반 상식·실제 사건을 담은 200문제(주관식 60문제)를 풀며 경험치와 장비를 얻습니다. 새 문제의 첫 정답은 기존 커뮤니티 보상에도 반영됩니다.

2026-09-27 배포판은 개인 원정, 아바타 이름과 모습 저장, 장비 그림, 보스 공격 패턴과 스킬 효과를 포함합니다. 기존 주간 퀴즈와 사용자 기록 구조는 유지했습니다.

게임 주소: https://legoschool.github.io/hanmadang-monster-battle/expedition.html

2026-10-07 이야기·전투 개편판은 한국어 내레이션이 나오는 38초 도입과 지역 이야기 음성 72개를 포함합니다. ‘소리 켜고 시작’을 누르면 음성에 맞춰 장면이 넘어갑니다. 전투 기본 속도는 1배이며, 타격 반동·스킬 등장 연출·보스와 펫 음성 안내를 추가했습니다. 기존에 저장한 속도와 소리 설정은 유지하며 ‘직접 스킬 쓰기 · 소리 켜기’로 바꿀 수 있습니다.

- 화면: 이 저장소의 `public/` 폴더가 깃허브 페이지로 배포됩니다.
- 기록 서버: 수파베이스(Supabase)에서 따로 운영합니다. 서버 코드에는 퀴즈 정답이 들어 있어 이 저장소에 올리지 않습니다.
- 서버 주소는 `public/js/config.js`의 `SUPABASE_URL`에서 정합니다.


전투 연출 확장판에는 대형 무기 궤적과 스킬, 확대된 캐릭터·보스, 등장·처치 연출, 합성 타격음, 선택형 배경 선율, 화면 효과 설정, 가입 없는 장비 체험 훈련장이 포함됩니다. 체험 전투는 기록과 보상을 저장하지 않습니다.

지식의 숲에는 지역별 원정 이야기가 있습니다. 도입, 길 위의 발견, 보스 대면, 봉인, 귀환 장면을 직접 넘겨 읽으며, 읽는 동안 전투가 멈춥니다. 로비의 ‘이야기 다시 읽기’는 같은 브라우저에서 만난 장면을 보관합니다.

플레이 라운지(public/lounge.html)는 기존 계정의 포인트로 선물에 응모하는 화면입니다. 관리자에서 선물 이름·사진·수량(1~999개), 마감 시각을 등록하고 수량별 가중 추첨 및 지급 확인을 처리합니다. 같은 선물은 1인 1개이며 서로 다른 선물에는 중복 당첨될 수 있습니다. 응모 예약은 사용 가능 포인트에서 차감되며 누적 랭킹은 유지됩니다. 회차를 취소하면 예약 포인트가 반환됩니다.

라운지에는 서버에서 판정하는 퀴즈·기억력 카드·3단계 숫자 탐색과 한국 시간 기준 일일 보상이 포함됩니다. 숫자 게임은 화면에서 즉시 반응하고 단계별 기록을 서버에서 검증합니다. 선물 정체와 퀴즈·카드의 비공개 정보는 공개 전까지 참가자에게 보내지 않습니다.

아케이드와 RPG 퀴즈 주제(프리셋)에는 G-DEAL 상식 28문항이 있습니다. 운영자 화면의 퀴즈 프리셋에서 주제를 고르고, 라운지·아케이드·RPG 퀴즈는 틀리면 정답과 해설을 보여 줍니다.

소리 재편집판(cinema2)은 도입 대사를 다시 만들고 침입·공격·출발 장면에 맞춰 음악과 충격음을 편집했습니다. 전투 배경음은 94.5초 관현악 구간으로 교체했고 대사 중에는 음악을 낮춥니다. 음악은 Scott Buckley의 Juggernaut(CC BY 4.0)이며, 편집 내역과 출처는 public/audio-credits.html 및 public/assets/audio/CREDITS.txt에 표기했습니다.

2026-10-07 게임 선택 개편(portal1): 메인의 ‘로그인 없이 둘러보기’는 games.html로 연결됩니다. 보스 돌파·아카이브 원정·버블 정원·별빛 비행대 4개를 실제 화면으로 고를 수 있으며 명시적 체험은 로그인 정보와 무관하게 서버 기록을 변경하지 않습니다. 게임의 나가기 동선은 게임 선택으로 돌아옵니다. 도입 영상은 선택 재생으로 바꾸고, 기록하며 플레이는 로그인 후 선택한 게임으로 연결합니다.

2026-10-07 공통 화면 개편(unified1): 메인·게임 선택·로그인·액션·RPG·아케이드·라운지는 public/css/service-theme.css의 배경, 패널, 글꼴, 버튼 색을 함께 사용합니다. 게임 입구의 로고와 게임 선택 메뉴는 public/js/service-shell.js를 공유합니다. 숲·우주 등 게임 장면의 그림과 체력·정오답 표시는 유지합니다.

2026-10-07 수동 전투 개편(combat1): 액션·버블·비행대는 공격 버튼 또는 Space/J를 누르는 동안 공격합니다. 이동과 공격을 동시에 조작할 수 있고 회피·스킬·펫 기술은 별도 버튼을 씁니다. 액션은 일반 적, 정예 돌진병, 선택 장비, 적 무리, 보스로 이어집니다. 정예의 벽 충돌과 보스 공격 후 반격, 충격파·갈래 탄환·파편·번개·회피 폭탄·회복 장비, 획득 출처와 결과 장비 표시, 같은 장비 재도전을 추가했습니다. RPG는 매 턴 공격·방어·펫·회복약을 직접 고르며 강공격 방어 후 반격과 위험 상자 선택을 반영했습니다. 아케이드 입력 검증은 v3이며 진행 중인 v2 기록의 서버 검증은 유지합니다.

2026-10-07 플레이 경험 정비(experience1): 첫 적을 가까이 배치하고 첫 조작 안내 중 펫의 선행 처치를 막았습니다. 전투 단계·상황별 조작 안내·목표 조준 표시를 묶고, 공격 버튼 위치 설정을 액션과 아케이드가 공유합니다. 회피의 무적 시간에 공격을 막으면 스킬 대기가 2초 줄어듭니다. 장비 선택은 공격 모양과 효과를 비교하며 전투 중 장비 확인, 피해 원인별 재도전 안내, 체험 전투 사이의 판단 문제를 제공합니다. RPG 행동 버튼에는 사용 효과와 부족한 자원을 표시합니다. 점수·계정 저장·서버 보상 규칙은 기존과 같습니다.
