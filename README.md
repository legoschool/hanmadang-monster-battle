# 지딜 학습 원정대

초등 5·6학년을 위한 과학·AI·디지털 통합 학습판입니다. 자료 관찰 → 문제 해결 → 해설 확인 → 내 말로 정리 → 복습 순서로 진행합니다. 조작 속도나 전투 성과 대신 근거를 읽고 설명하는 활동에 학습 경험치를 연결합니다.

2026-11-17 학습판의 소스를 추가했습니다. 배포와 검증 상태는 로컬 문서 `design/learning-20261117/HANDOFF.md`에서 따로 관리합니다.

## 학습 구성

| 구분 | 주제 | 문항 수 |
|---|---|---|
| 과학 | 빛의 성질 · 전기 회로 · 에너지와 절약 · 지구와 계절 | 주제별 6개, 총 24개 |
| 과학과 AI·디지털 | AI와 과학 탐구 · 디지털 안전 · 과학 데이터 읽기 · 실험과 알고리즘 | 주제별 6개, 총 24개 |

본 학습은 48문항입니다. 모든 문항에 관찰 자료, 네 보기, 생각 힌트, 해설이 있습니다. 시간 제한 없이 다시 시도하며, 틀렸거나 힌트를 사용한 문제는 복습에 모입니다. 별도 복습에서 힌트 없이 첫 시도에 해결하면 복습 목록에서 빠집니다.

주제의 문제를 해결하고 해설을 확인한 뒤 기록을 저장하면, 처음 완료한 문항마다 학습 경험치 10을 받습니다. 현재 48문항으로 받을 수 있는 경험치는 계정당 최대 480입니다. 같은 문항을 반복하거나 저장 요청을 다시 보내도 경험치는 중복 지급하지 않습니다. 단원평가 점수와는 다른 기록입니다.

로그인 없는 체험은 주제마다 별도로 작성한 한 문제씩, 총 8문항입니다. 본 학습의 정답을 공개하지 않으며 체험 결과는 계정 기록과 보상에 반영하지 않습니다. 본 학습 문항·정답은 `server/learning-bank.js`, 공개 학습 목표는 `public/js/learning-units.js`, 체험 문항은 `public/js/learning-demo.js`에서 관리합니다.

## 함께하기와 기록

협동 방은 제목·주제·정원(2~6명)·선택 비밀번호를 정해 만듭니다. 서버의 방 목록에서 공개 방에 바로 참가하고, 잠긴 방은 비밀번호를 확인합니다. 방장이 두 명 이상 모인 뒤 시작하면 같은 문제를 받고, 모두 문제를 해결하고 해설을 확인한 뒤 다음 문제로 이동합니다. 진행 중인 방에는 새로 참가하지 않습니다. 경쟁 팀전은 제공하지 않습니다.

본 학습의 채점·중복 보상 방지·방 상태는 서버가 처리합니다. 학습 기록에는 첫 시도, 다시 시도, 힌트 사용, 내 말로 정리한 내용을 남깁니다. 방 목록·협동 진행 구현, 로컬 시험, 운영 서버 연결, 실제 두 클라이언트 검증은 별도 확인 항목입니다.

통합 허브에서 로그인한 뒤 게임 목록의 **지딜 학습 원정대**를 누르면 같은 통합 계정으로 입장합니다. 닉네임과 계정 설정은 허브에서 관리하며, 학습 기록은 통합 계정에 저장합니다. 이전 지딜 계정의 기록은 계정 화면에서 별도로 열 수 있고 닉네임만으로 통합 계정에 합치지 않습니다.

## 통합 별

6학년 통합 계정에는 다른 게임과 같은 별 규칙을 적용합니다. 정답 1~5회마다 별 1개, 6문제 원정을 완료하고 기록을 저장하면 별 3개를 받습니다. 하루 지딜 최대 15개, 모든 게임을 합쳐 최대 50개이며, 공통 서버에서 한국 시간 기준으로 계산합니다. 화면의 **내 통합 별**은 허브와 같은 사용 가능 잔액입니다.

별은 서버가 확인한 정답과 완료 사건에만 지급합니다. 같은 사건의 재요청·새로고침으로 중복 지급하지 않으며, 지급 간격이나 일시적인 연결 문제로 처리하지 못한 별은 대기 상태로 보존하고 다시 확인합니다. 체험과 이전 지딜 계정에는 통합 별을 지급하지 않습니다. 학습 경험치는 문제 해결 기록으로 유지하며 별로 환산하지 않습니다.

## 시작 주소와 이전 행사판

학습판 파일은 `public/learn.html`입니다. 배포 후 주소는 https://legoschool.github.io/hanmadang-monster-battle/learn.html 입니다.

기존 `index.html`, `games.html`, `expedition.html`, `rpg.html`, `arcade.html`, `lounge.html`, `duel.html` 북마크는 학습판으로 이동하도록 바꿨습니다. 예전 운영 화면은 해당 주소에 `?legacy=1`을 붙여 직접 열 수 있으며 기존 관리자 경로도 보존합니다. 이전 행사판의 계정과 기록을 초기화하는 변경은 아닙니다.

화면은 `public/`을 GitHub Pages에, 기록 서버는 Supabase Edge Function `api`에 배포합니다. **서버 코드와 본 학습 정답은 공개 Git 저장소에 올리지 않습니다.** 통합 허브는 https://science-hub-one.vercel.app/student.html 입니다. 운영 배포 및 검증 근거는 로컬 인수인계 문서에서 관리합니다.

전투 연출 확장판에는 대형 무기 궤적과 스킬, 확대된 캐릭터·보스, 등장·처치 연출, 합성 타격음, 선택형 배경 선율, 화면 효과 설정, 가입 없는 장비 체험 훈련장이 포함됩니다. 체험 전투는 기록과 보상을 저장하지 않습니다.

지식의 숲에는 지역별 원정 이야기가 있습니다. 도입, 길 위의 발견, 보스 대면, 봉인, 귀환 장면을 직접 넘겨 읽으며, 읽는 동안 전투가 멈춥니다. 로비의 ‘이야기 다시 읽기’는 같은 브라우저에서 만난 장면을 보관합니다.

플레이 라운지(public/lounge.html)는 기존 계정의 포인트로 선물에 응모하는 화면입니다. 관리자에서 선물 이름·사진·수량(1~999개), 마감 시각을 등록하고 수량별 가중 추첨 및 지급 확인을 처리합니다. 같은 선물은 1인 1개이며 서로 다른 선물에는 중복 당첨될 수 있습니다. 응모 예약은 사용 가능 포인트에서 차감되며 누적 랭킹은 유지됩니다. 회차를 취소하면 예약 포인트가 반환됩니다.

라운지에는 서버에서 판정하는 퀴즈·기억력 카드·3단계 숫자 탐색과 한국 시간 기준 일일 보상이 포함됩니다. 숫자 게임은 화면에서 즉시 반응하고 단계별 기록을 서버에서 검증합니다. 선물 정체와 퀴즈·카드의 비공개 정보는 공개 전까지 참가자에게 보내지 않습니다.
